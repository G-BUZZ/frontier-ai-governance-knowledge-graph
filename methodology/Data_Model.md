# Data Model

The knowledge graph represents entities (nodes) and documented relationships (edges) extracted from publicly available sources.

## Node Types

- Organization
- Frontier Model
- Governance Framework
- Evaluation
- Benchmark
- Capability
- Risk Domain
- Deployment Control
- Incident
- Regulation
- Standard
- Publication

## Edge Types

- develops
- publishes
- evaluates
- recommends
- mitigates
- regulates
- references
- adopts
- supersedes
- reports
- requires
- supports

## Evidence

Every edge must reference at least one primary source.

Each relationship includes:

- source
- publication date
- evidence excerpt
- confidence level
- reviewer
